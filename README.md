# フリック練習＆記録アプリ

iPhone風のフリックキーボードでタイピング練習ができ、結果（速さ・ミス数）が自動で記録されるアプリです。
他サイト（寿司打など）の結果を手動で記録することもできます。
`index.html` の **1ファイルだけ**で動きます。インストールは不要です。

## 使い方

**スマホ・PCから開く（おすすめ）**
https://maruhashi-creator.github.io/typing-app/ を開きます。
スマホでは「ホーム画面に追加」しておくと、アプリのように起動できます。

**PCでファイルを直接開く**
`index.html` をダウンロードしてダブルクリックすると、ブラウザで開きます。

## 練習のやり方

- 「練習をはじめる」を押すと、画面下にフリックキーボードが出ます。
- キーを押したまま上下左右にスライドすると入力できます（タップ＝あ段、左＝い段、上＝う段、右＝え段、下＝お段）。
- 濁点・半濁点・小さい文字は「小゛゜」キーで切り替えます（例：か→が、つ→っ→づ、は→ば→ぱ）。
- 10問終わると、速さ（文字/分）・ミス数・正確さが表示され、履歴に自動で保存されます。
- PCではマウスでドラッグすると同じように練習できます。

## データの保存先について

- 記録はブラウザの中にある **localStorage**（ブラウザ内蔵の小さな保存領域）に保存されます。
- ページを閉じても、再読み込みしても、記録は残ります。
- ただし、**別のブラウザや別の端末（PCとスマホなど）とは共有されません。**
- ブラウザの「閲覧データの削除」を行うと、記録も消えます。

## ファイルの中身（3つの役割）

| 部分 | 役割 |
|---|---|
| `<style>` … CSS | 見た目（色・余白・スマホ向けレイアウト） |
| `<form>` など … HTML | 画面の部品（入力欄・ボタン・一覧） |
| `<script>` … JavaScript | 動き（フリック判定・練習の進行・保存・一覧表示・削除） |

## 次の一歩（候補）

- お題の文を増やす（`PHRASES` の一覧に足すだけ）
- サイト別の平均スコアやベストスコアを表示する
- 記録のバックアップ（書き出し・読み込み）
